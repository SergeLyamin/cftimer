# Архив наследия

По решению владельца от 22.10.2026 старое приложение вынесено из активного проекта. Архив нужен для изучения поведения и выборочного повторного использования после проверки.

| Каталог | Что сохранено | Ограничения |
| --- | --- | --- |
| `legacy-worktree/` | Точное состояние исходников, package/lock, конфигураций, тестов, `.kiro`, `Docs old` и прототипа rings до переноса, включая незакоммиченные изменения | Незавершённое переписывание; не рабочий baseline |
| `legacy-git-d3e506f/` | Все 42 отслеживаемых файла из коммита `d3e506f`; полный hash в manifest | Историческая версия, а не подтверждённый последний рабочий релиз; сервер не изолирует залы |
| `documentation-before-sdd/` | README, .gitignore и шесть прежних файлов docs на момент миграции | Старые планы и обещания, не действующие требования |
| `graphify-audit-2026-10-22/` | [Карта исходного scaffold](graphify-audit-2026-10-22/graph.html), JSON и отчёт | Только четыре TS-файла до переноса; пути в графе относительны прежнему src |

[Manifest](manifest-2026-10-22.json) содержит SHA-256 для 77 исходных/исторических файлов и отдельно для одного сгенерированного cache-файла аудита. Их байтовая идентичность проверена после переноса. Исторический export сохраняет содержимое файлов; executable bits экспортом не воспроизводятся. Исторический `.gitignore` сохранён как `.gitignore.reference` с тем же содержимым, чтобы его старые правила не исключили шрифты из нового архива. Установленные `node_modules` и прежние browser reports перенесены локально, но не включаются в Git и manifest.

Git-история не переписывалась, коммиты не создавались. Макеты `design/` сохранены в активном проекте. Папка `CF Timer2` не использовалась как источник.

Архивные `AGENTS.md`/инструкции и старые чекбоксы не задают правила активной разработки. Не запускать архивный deploy; не копировать сервер и протокол wholesale. Для просмотра логики см. `legacy-git-d3e506f/www/timer.js` и `www/js/components/`, учитывая выводы аудита.
