# Техническое задание CrossFit Timer v2.0

## 1. Общие сведения

### 1.1 Наименование системы
CrossFit Timer v2.0 - веб-приложение для проведения кроссфит тренировок

### 1.2 Назначение системы
Система предназначена для:
- Проведения различных типов спортивных тренировок с таймерами
- Удаленного управления тренировками через мобильные устройства
- Отображения информации о ходе тренировки на больших экранах
- Звукового сопровождения тренировочного процесса

### 1.3 Цели создания системы
- Модернизация существующего приложения с улучшением архитектуры
- Повышение точности и надежности таймеров
- Улучшение пользовательского опыта
- Обеспечение расширяемости для добавления новых функций

## 2. Функциональные требования

### 2.1 Типы таймеров

#### 2.1.1 Интервальный таймер
**Описание**: Таймер для интервальных тренировок с чередованием работы и отдыха

**Параметры настройки**:
- Количество кругов (1-99)
- Количество раундов в круге (1-99)
- Время работы (секунды: 0-59, минуты: 0-59)
- Время отдыха (секунды: 0-59, минуты: 0-59)
- Время подготовки (обратный отсчет): 3-30 секунд

**Поведение**:
- Обратный отсчет подготовки с звуковыми сигналами
- Чередование фаз работы и отдыха
- Отображение текущего раунда и круга
- Звуковые сигналы при смене фаз
- Финальный сигнал по завершению

#### 2.1.2 FOR TIME таймер
**Описание**: Прямой отсчет времени для тренировок на время

**Параметры настройки**:
- Целевое время (минуты: 0-59, секунды: 0-59)
- Время подготовки: 3-30 секунд

**Поведение**:
- Обратный отсчет подготовки
- Прямой отсчет времени от 00:00
- Возможность остановки при достижении цели
- Звуковые сигналы старта и финиша

#### 2.1.3 AMRAP таймер
**Описание**: Обратный отсчет для тренировок "максимум раундов"

**Параметры настройки**:
- Общее время тренировки (минуты: 1-60)
- Время подготовки: 3-30 секунд

**Поведение**:
- Обратный отсчет подготовки
- Обратный отсчет основного времени
- Звуковые предупреждения (за 3, 2, 1 минуту до конца)
- Финальный сигнал

#### 2.1.4 Часы
**Описание**: Отображение текущего времени и дополнительные функции

**Функции**:
- Текущее время (часы:минуты:секунды)
- Секундомер
- Простой таймер обратного отсчета

### 2.2 Управление

#### 2.2.1 Локальное управление
**Клавиатурные команды**:
- `Пробел` - старт/пауза таймера
- `R` - сброс таймера
- `F` - переключение полноэкранного режима
- `Esc` - выход из полноэкранного режима

**Сенсорное управление**:
- Тап по экрану - старт/пауза
- Долгое нажатие - сброс
- Свайп вверх - полный экран

**Кнопки интерфейса**:
- Кнопки старт/пауза/сброс
- Кнопка полного экрана
- Кнопки настроек

#### 2.2.2 Удаленное управление
**QR-код подключение**:
- Генерация уникального QR-кода для сессии
- Отображение QR-кода в интерфейсе
- Автоматическое обновление при смене сессии

**WebSocket соединение**:
- Установка соединения по QR-коду
- Синхронизация состояния таймера
- Передача команд управления
- Автоматическое переподключение при разрыве

**Команды удаленного управления**:
- Старт/пауза таймера
- Сброс таймера
- Переключение полного экрана
- Изменение настроек звука

### 2.3 Пользовательский интерфейс

#### 2.3.1 Главный экран
**Элементы**:
- Меню выбора типа таймера (4 кнопки)
- Кнопка QR-кода (правый нижний угол)
- Логотип/название приложения
- Индикатор подключения

**Поведение**:
- Адаптивная сетка кнопок
- Анимация при наведении/нажатии
- Модальное окно с QR-кодом

#### 2.3.2 Экраны настройки
**Общие элементы**:
- Заголовок с названием типа таймера
- Поля ввода параметров
- Кнопка "Старт"
- Кнопка "Назад"

**Валидация**:
- Проверка диапазонов значений
- Подсветка некорректных полей
- Блокировка старта при ошибках

#### 2.3.3 Экраны выполнения
**Основные элементы**:
- Большой дисплей времени (центр экрана)
- Индикатор текущей фазы
- Счетчик раундов/кругов (для интервального)
- Кнопки управления (старт/пауза/сброс)
- Индикатор подключения удаленного управления

**Адаптивность**:
- Масштабирование шрифта под размер экрана
- Перестройка элементов для мобильных устройств
- Поддержка горизонтальной/вертикальной ориентации

### 2.4 Звуковая система

#### 2.4.1 Типы звуковых сигналов
- **Подготовка**: короткие сигналы (3-2-1)
- **Старт**: длинный сигнал начала
- **Смена фазы**: средний сигнал перехода
- **Предупреждение**: серия коротких сигналов
- **Финиш**: длинный финальный сигнал

#### 2.4.2 Настройки звука
- Включение/выключение звука
- Регулировка громкости (0-100%)
- Выбор набора звуков (опционально)

## 3. Нефункциональные требования

### 3.1 Производительность
- Время загрузки приложения: не более 2 секунд
- Точность таймеров: ±50 миллисекунд
- Отзывчивость интерфейса: не более 100 миллисекунд
- Плавность анимаций: 60 FPS

### 3.2 Надежность
- Время безотказной работы: 99.5%
- Автоматическое восстановление WebSocket соединений
- Сохранение состояния при перезагрузке страницы
- Graceful degradation при отключении JavaScript

### 3.3 Совместимость

#### 3.3.1 Браузеры
**Десктоп**:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

**Мобильные**:
- iOS Safari 14+
- Android Chrome 90+
- Samsung Internet 13+

#### 3.3.2 Устройства
**Разрешения экрана**:
- Десктоп: 1920x1080 и выше
- Планшеты: 768x1024 и аналогичные
- Мобильные: 375x667 и выше

**Ориентация**:
- Портретная (мобильные, планшеты)
- Альбомная (десктоп, планшеты)

### 3.4 Безопасность
- Валидация всех пользовательских данных
- Защита от XSS атак
- Безопасные WebSocket соединения (WSS в продакшене)
- Ограничение частоты запросов

### 3.5 Доступность
- Поддержка screen readers
- Клавиатурная навигация
- Достаточный цветовой контраст (WCAG 2.1 AA)
- Масштабируемые шрифты

## 4. Технические требования

### 4.1 Архитектура
- Модульная архитектура с четким разделением ответственности
- Event-driven взаимодействие между компонентами
- Dependency injection для слабой связанности
- Immutable state management

### 4.2 Технологический стек

#### 4.2.1 Frontend
- TypeScript 5.0+ (строгий режим)
- Vite (сборка и dev-сервер)
- Tailwind CSS (стилизация)
- PostCSS (обработка CSS)
- ESLint (линтинг)

#### 4.2.2 Backend
- Node.js 18+ (серверная платформа)
- Express (веб-фреймворк)
- WebSocket (ws библиотека)
- QRCode (генерация QR-кодов)

#### 4.2.3 Тестирование
- Jest (unit тестирование)
- Playwright (E2E тестирование)
- TypeScript (типизированные тесты)

### 4.3 Качество кода
- Покрытие тестами: минимум 80%
- Линтинг без ошибок
- Типизация всех публичных API
- Документирование сложных алгоритмов

## 5. Ограничения и допущения

### 5.1 Ограничения MVP
- Нет сохранения пользовательских пресетов
- Нет истории тренировок
- Нет интеграции с внешними сервисами
- Один активный таймер на сессию

### 5.2 Технические ограничения
- Работа только в современных браузерах
- Требуется JavaScript для полной функциональности
- WebSocket для удаленного управления
- Локальное хранение настроек

### 5.3 Допущения
- Стабильное интернет-соединение для удаленного управления
- Поддержка HTML5 Audio API
- Поддержка localStorage
- Поддержка WebSocket API

## 6. Критерии приемки

### 6.1 Функциональные критерии
- Все типы таймеров работают согласно спецификации
- Удаленное управление функционирует стабильно
- Звуковые сигналы воспроизводятся корректно
- Интерфейс адаптируется под разные устройства

### 6.2 Технические критерии
- Покрытие тестами > 80%
- Отсутствие критических ошибок в консоли
- Соответствие требованиям производительности
- Кроссбраузерная совместимость

### 6.3 Пользовательские критерии
- Интуитивно понятный интерфейс
- Быстрое подключение удаленного управления
- Стабильная работа в течение тренировки
- Корректное отображение на всех устройствах
