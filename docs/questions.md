# Решения и оставшиеся вопросы

## Подтверждено 22.10.2026

Один экран и один активный таймер; любой пользователь; первый QR-пульт без подтверждения; второй запрашивает разрешение первого; после разрешения право переходит второму. Нет связи первого 60 секунд → новому можно подключиться автоматически. Возвратившийся старый пульт не отбирает управление. Reload компьютера сбрасывает таймер/сессию; reload телефона-пульта только переподключает. Аккаунты и роль тренера не нужны. Стек принят, ImageGen-направление принято. Сервер хранит лишь сессии и журналы; диагностика через SSH.

Пилот 1–3 зала с PC+TV; запуск с экрана работает без телефона. CrossHero — основной референс; CoachTimer — близкий аналог. Старый код архивирован.

## Уточнить позже, не повторяя уже решённое

1. **Программы:** 2–3 реальных примера с подготовкой, раундами, работой/отдыхом; нужен ли отдых после последнего? Сейчас предложено без последнего отдыха.
2. **Звук:** колонки компьютера, телевизора или внешняя акустика; музыка одновременно?
3. **Сервер и домен:** провайдер/ОС, где старый сайт, будущий staging-поддомен. Секреты в документацию не нужны.
4. **Оборудование пилота:** ОС/браузер PC, iPhone/Android; даты доступных занятий.
5. **Offline:** необходимость LAN-пульта без внешнего интернета остаётся будущим выбором; пилот использует облачный relay.
6. **Журналы:** предложены 14 дней и лимит диска; перед production выбрать значения и события внешней аналитики.

Шаблон ответа: `1: 8×20/10 + 10с подготовка; 2: колонки PC; 3: ...; 4: ...`. Неизвестные пункты можно оставить на следующий этап.

Параметры, пока предложенные дизайнером: запрос передачи истекает через 20 секунд без согласия при живом пульте; повторные запросы ограничиваются. Они не заменяют подтверждённые 60 секунд потери связи и могут быть скорректированы до implementation.

## Новые решения и вопросы по мобильной версии

Подтверждены владельцем: самостоятельный смартфон без QR/функций пульта при обычном входе; на больших экранах QR можно свернуть; нужны авторство, репозиторий, политика при применимости; код/другие способы подключения — будущий бэклог. Ранее согласованный пульт по явному приглашению сохраняется.

7. **Конфиденциальность:** получен ответ «РФ». Статус оператора (физлицо / ИП / компания), публичное имя, контакт и точный охват аудитории пока не указаны; политика остаётся проектом.
8. **Мобильная главная — решено:** всегда A, только выбор режима; B не используем.
9. **Настройки — решено направление:** проще, только основные поля. Предлагаем вынести подготовку и звук в «Дополнительно», сохранив краткий итог с указанием подготовки.

Позже достаточно дополнить: `оператор: физлицо / ИП / компания; имя: …; контакт: …; аудитория: …`. Уже выбранную главную и направление упрощения повторно согласовывать не нужно.

Подтверждено дополнительно: стиль макетов подходит; ввод времени — цифрами по шаблону с системной цифровой клавиатурой Android/iOS. Подсветка переходов/завершения внесена как открытый вопрос BL-08.
