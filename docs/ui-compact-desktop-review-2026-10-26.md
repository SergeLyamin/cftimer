# Компактный таймер — desktop review 26.10.2026

Вторая локальная итерация после [предыдущего просмотра](ui-phase-desktop-review-2026-10-26.md). Адрес: http://127.0.0.1:5173/. Одобрение владельца ожидается; эти изменения не опубликованы.

- Summary «Подготовка», поле сразу под ним без повторного видимого label, доступное имя сохранено. После «Старт» — только «Общее время: …».
- Фазовая полоса 50 px с прямыми углами. Вместо номерных квадратов — шкала работы/отдыха 20 px с пропорциональной длительностью сегментов: work красный, rest голубой, пройденное заполнено, будущее серое с фазовой окантовкой. Подготовка и последний отдых в неё не входят.
- Пауза/продолжение и сброс — круги 40×40 с иконками и доступными именами. Сброс выплывает справа из-под основной кнопки; её положение не меняется. Немедленный перезапуск сохранён.
- Заголовки: название интервального режима и N из M; For Time — настроенный лимит. Стрелка меню с тонкой круглой окантовкой.
- Удержание экрана и готовность offline, включая retry/repair, перенесены в уведомления настроек. Постоянные строки убраны с главной и таймера.

Минимальная проверка: desktop Chromium 1280×800, форма, геометрия/появление кнопок, пять сегментов для трёх раундов, частичное заполнение, отдых и заголовок For Time 10:00. Typecheck, targeted lint и 13 затронутых unit-тестов фазовой/сегментированной полосы прошли. Остальные проверки и исправление прежних browser assertions — после UI approval; публикация требует отдельной отмашки.
