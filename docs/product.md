# Продукт и пилот

Обновлено 22.10.2026. Подтверждённая концепция: **самостоятельный таймер на смартфоне и общий таймер с необязательным пультом на больших экранах**, основной референс [CrossHero](https://timer.crosshero.com/). Локальный runtime реализован; приёмка на устройствах открыта, QR-пульт пока в плане.

## Подтверждено владельцем

- Бесплатный пилот в 1–3 залах; в каждом сценарии один компьютер с телевизором и один активный таймер.
- Любой человек запускает/настраивает таймер на компьютере или через QR-пульт. Нет аккаунтов, роли тренера, PIN, кабинета зала и регистрации.
- Смартфон по обычному адресу — личный таймер без QR и управления с другого телефона; явное приглашение общего экрана открывает пульт. Большие экраны — обычный режим с QR, который можно свернуть. Подробности маршрутизации — [UX](ux.md).
- Один активный телефон-пульт. Первое подключение свободно; следующее требует разрешения текущего пульта и передаёт управление, а не создаёт второго writer.
- После 60 секунд отсутствия связи текущего пульта новый получает управление без согласия. Возвратившийся прежний пульт видит потерю доступа.
- Перезапуск страницы компьютера сбрасывает тренировку и сессию. Перезапуск страницы телефона-пульта только переподключает его; самостоятельный мобильный таймер имеет собственное локальное состояние.
- Начатая тренировка продолжает работать без интернета. Управление по LAN без WAN — отдельный возможный этап.
- Принят стек TypeScript/React/Vite/Tailwind, Node relay; server stores только временные сессии и журналы, без базы аккаунтов/программ.
- Smart/Android TV — backlog. Старое наследие — reference в архиве.
- Утверждено направление [двух ImageGen-концептов](ux.md), детали проверяются в реализации.

## Ценность и отличие

Задача: открыть страницу и начать занятие на своём телефоне или общем экране; общим экраном при желании управлять с телефона. Сегментация по должности человека внутри приложения не нужна. Целевой путь — прямой вход в таймер без лендинга, крупное время, понятная смена пульта, отсутствие установки и аккаунта.

[CoachTimer](https://coachtimer.app/) очень близок и тоже работает без обязательного аккаунта. Сам QR, отсутствие аккаунта и телефонный пульт не уникальны. Отстройку проверяем качеством простого сценария, понятным takeover и надёжностью локального времени. Утверждать, что конкуренты этого не умеют, без теста нельзя.

## Этапы

| Этап | Результат | Проверка |
| --- | --- | --- |
| Подготовка | Аудит, архив, OpenSpec, UX и согласованные решения | Выполнены; локальный runtime проходит приёмку |
| Локальный таймер | AMRAP, For Time, интервалы, пресеты, звук, cached offline startup, самостоятельный мобильный UI | Граничные unit tests, browser E2E, часовой прогон, сброс при reload |
| Пульт | QR, один владелец, запрос/отказ/передача, 60-секундное ожидание, reconnect | Два телефона + независимый экран другого посетителя сервиса; гонки/отказы не нарушают изоляцию |
| Наблюдаемость и staging | Логи, SSH-инструменты, HTTPS/WSS, rollback | Реальные WSS, safe logs, restart relay, offline display |
| Пилот | 20 занятий суммарно в 1–3 залах | Без ошибок времени/фаз, ≥90% без помощи разработчика; повторное использование |

Один экран в зале не означает один глобальный экран у всего сервиса: разные открытые экземпляры на разных компьютерах должны быть изолированы техническими сессиями. Эта деталь не выводится пользователю как кабинет/организация/список залов.

Предлагаемые метрики: 9/10 первых подключений без помощи, медиана ≤20 с и p90 ≤40 с; локальное продолжение при обрыве 60 с; корректная передача после выбранного таймаута; добровольное повторное использование. Это пороги проверки, не достигнутые показатели.

## Приоритеты

Предлагаемый порядок новых задач — [бэклог BL-01–07](backlog.md); сроки включения в пилот ещё не назначены.

P0: точное время, локальные кнопки на PC и телефоне, настройки, сворачиваемый QR общего экрана, явные состояния пульта, безопасное завершение, продолжение без сети, диагностика.

P1: локальные пресеты, обмен программой без аккаунта, опциональная вибрация на поддерживаемых телефонах, WOD рядом с таймером после проверки читаемости.

P2: подключение по коду/ручной ссылке, исследование трансляции, LAN offline remote, Smart/Android TV, составные программы. Несколько зон, кабинеты сотрудников, командные библиотеки и биллинг не входят в текущую концепцию; прежние предложения остаются только гипотезами исследования.

## Данные

Сессии в памяти сервера; структурированные журналы и отчёты по SSH. Дополнительно владелец планирует Яндекс Метрику и Google Analytics. Что и как измеряем без аккаунтов — [operations.md](operations.md). [Проект политики](privacy-policy-draft.md) требует данных оператора и сверки с фактическим релизом; публикация приложения не означает автоматическое включение счётчиков. Можно понять сценарии использования, но нельзя достоверно посчитать людей или установить личности по сессиям.
