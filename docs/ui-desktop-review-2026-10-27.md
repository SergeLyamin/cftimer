# Локальная desktop-итерация — 27.10.2026

Изменения по замечаниям владельца после 0.1.4. Production остаётся **0.1.4**. Следующая версия не опубликована; разрешение на её выпуск не получено. Локальная реализация и первичная desktop-проверка выполнены; владелец затем одобрил UI, расширенные программные проверки выполнены — [результаты кандидата 0.1.5](ui-0.1.5-2026-10-27.md).

## Что проверить локально

- На главной сразу пять режимов: без «ВАША ТРЕНИРОВКА» и «Выберите режим».
- Focus полей по смыслу: раунды белые, работа `#EF4A40`, отдых `#59B8E8`, подготовка `#F2A541`; отдельные ошибки и доступные подписи сохранены.
- Основное время без видимых двоеточий, с прежним интервалом между парами и обычным доступным форматом. Шкала раундов **3 px**, основной прогресс **50 px**, направления/фазы прежние.
- Пауза/продолжение **56×56 px**, боковые действия **40×40 px**, зазор **28 px** с обеих сторон. На паузе слева карандаш редактирования, справа сброс; центральная кнопка не сдвигается. Редактирование открывает те же параметры, новый отсчёт только по «Старт»; сброс сразу повторяет с подготовкой.
- Естественный конец: «ТЫ МОЛОДЕЦ! 🏆», итоговое время и повтор, обе полосы скрыты. Конфетти оседает внизу и остаётся статичным до ухода/повтора/выключения, без бесконечной отрисовки.
- При включении звука слышен один проверочный сигнал, отдельного пункта проверки нет. При включении пульсации/конфетти видно краткое демо; открытие настроек с сохранённым on не запускает его. Демо не меняет таймер, выключение/закрытие прекращает его; reduced motion/hidden подавляют визуальные демо.

## Этапы приёмки

1. Локальная реализация и только необходимые проверки desktop. Фактические результаты и снимки добавляются после выполнения.
2. Владелец проверяет локальную desktop-версию и даёт явное UI approval. Замечания возвращают работу на первый этап.
3. После UI approval выполняются остальные mobile/responsive/cross-browser/regression/offline/PWA и необходимые программные проверки. Реальные iPhone/Android и PC+TV не считаются проверенными по screenshots/mocks.
4. Публикация только после успешных проверок и отдельной отмашки владельца на этот выпуск.

Реализация и desktop evidence отмечены в 13.1–13.5 `bootstrap-timer-pilot/tasks.md`; 13.6–13.7 выполнены после подтверждения владельца; 13.8 (публикация) остаётся открытым. Предыдущие результаты 0.1.4 остаются в [историческом отчёте](ui-0.1.4-2026-10-26.md).


## Выполнено локально

Chromium, desktop **1440×1000**, локальный Vite `http://127.0.0.1:5173/`. Проверки через Playwright CLI; полный E2E/mobile/PWA прогон намеренно отложен до одобрения UI.

- TypeScript (`npm run typecheck`) и ESLint шести изменённых TSX-компонентов прошли; `git diff --check` чисто. OpenSpec strict: 4/4.
- Измерены 56×56 и 40×40 px, оба зазора 28 px, шкала 3 px. Пустой разделитель сохранил ширину 70.398 px при этом размере шрифта; доступное время продолжает содержать двоеточие.
- Проверены все четыре focus-цвета; параметры сохранились после редактирования, «Старт» и «Сброс» начинают подготовку. Клик по шкале ставит на паузу и продолжает; невидимая область попадания вокруг линии — 24 px.
- Интервалы естественно завершились с новой надписью, без полос. После ещё 6 с все 15 814 непрозрачных пикселей canvas находились в нижних 60 px: осевшее конфетти не исчезло. Код завершает RAF при оседании всех частиц.
- Демо пульсации заканчивается через 4 с и повторяется после закрытия/повторного открытия настроек. Конфетти-демо очищается примерно через 5 с. Закрытие настроек удаляет preview; при reduced motion визуальных preview нет. Демо на главной и при running не переключает состояние таймера. Подавление hidden проверено симуляцией visibilitychange, не реальным уходом приложения в фон.
- Включение звука успешно вызвало локальную проверку AudioContext; реальная слышимость на устройстве владельца требует ручной проверки. Отдельной кнопки проверки нет.
- В консоли браузера только сообщения React DevTools, ошибок приложения нет. Старый dev-сервер держал версию 0.1.2 из конфигурации запуска; перезапущен только локальный Vite, настройки теперь показывают актуальную 0.1.4 из package.json. Новый номер релиза пока не назначался.
