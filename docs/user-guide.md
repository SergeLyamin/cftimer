# Локальный таймер: короткая инструкция

Инструкция описывает согласованный интерфейс 0.1.2; публикация и аппаратная приёмка проверяются отдельно.

1. Выберите режим. Время вводится четырьмя цифрами, двоеточие появляется автоматически. Неполный ввод, неверные секунды и слишком длинная вставка не запускают тренировку. В «Дополнительно» меняется подготовка; итог «Всего времени» у интервалов, Tabata и EMOM включает её и не содержит отдыха после последнего раунда.
2. Шестерёнка перед кнопкой fullscreen доступна на всех экранах. В настройках можно включить звук, услышать проверочный сигнал и отключить эффекты. По умолчанию звук выключен, эффекты включены; выбор сохраняется на этом устройстве, при недоступном сохранении — до закрытия страницы. Системное уменьшение движения отключает подсветку. Внизу окна — версия сборки и «GitHub автора».
3. Нажмите «Начать». Полоса показывает остаток всей программы; её цвет и название фазы: оранжевая подготовка, красная работа, голубой отдых. Цифры остаются белыми. На интервалах видны все номера раундов: завершённые белые, оставшиеся красные, текущий с рамкой. Раунд завершён после отдыха, последний — после работы. При большом числе раундов прокрутите страницу; нижние действия остаются доступны.
4. «Пауза» останавливает отсчёт. На паузе доступны «Продолжить» и меньший «Сброс»: сброс **сразу**, без подтверждения запускает ту же программу заново с подготовкой. Верхняя стрелка слева от названия после подтверждения прерывает занятие и возвращает к режимам; результат появляется после естественного окончания. После результата «Повторить» запускает ту же программу, стрелка открывает меню сразу.
5. На компьютере Space ставит на паузу/продолжает вне полей и интерактивных элементов, Escape **только на паузе** запускает программу заново, F переключает fullscreen. В открытом окне Escape сначала закрывает его; выход из fullscreen через Escape не сбрасывает таймер. Во время ввода, с модификаторами и при удержании клавиши команды не исполняются.
6. Таймер запрашивает удержание экрана и при необходимости восстанавливает его после возврата/освобождения ограниченным числом попыток. Надпись «Экран остаётся включённым» появляется после подтверждения браузером. Если удержание не активно, нажмите «Не выключать экран»; при отказе отключите автоблокировку вручную. При выходе из занятия удержание снимается. Фоновая вкладка и блокировка кнопкой устройства не входят в гарантию.

Начатый таймер не требует интернета. Для повторного открытия без сети дождитесь «Готов к запуску без сети» на главной. Кнопка «Подготовить офлайн» повторяет проверку/восстановление кэша при наличии интернета. Первый визит без сети не поддерживается.

Перезагрузка страницы сбрасывает текущую тренировку: сохраняются только параметры. При доступном обновлении завершите тренировку, закройте все вкладки приложения и откройте заново. Другую работающую вкладку не нужно закрывать посреди занятия.

QR-пульт ещё не реализован. Трансляция на TV, фоновый будильник при блокировке телефона и автономное LAN-управление в эту версию не входят.
