# Локальный таймер: короткая инструкция

Инструкция описывает согласованный интерфейс 0.1.3; статус публикации и проверок — в [отчёте](ui-0.1.3-2026-10-26.md).

1. Выберите режим. Время вводится четырьмя цифрами, двоеточие появляется автоматически. Работа и отдых принимают до 99:99; пятая цифра игнорируется, числовые переполнения ограничиваются. Неполный/нечисловой ввод блокирует старт. Раунды ограничены 99. В свёрнутой «Подготовке» меняется время подготовки; «Общее время» под «Старт» включает её и не содержит отдыха после последнего раунда.
2. Шестерёнка перед fullscreen доступна на всех экранах. Здесь звук, проверочный сигнал, пульсация и конфетти. По умолчанию звук выключен, эффекты включены; выбор сохраняется на устройстве, при запрете сохранения — до закрытия страницы. Системное уменьшение движения отключает анимации. Внизу — версия сборки и «GitHub автора».
3. Нажмите «Старт». Основная полоса показывает только текущую фазу: оранжевая подготовка, красная работа, голубой отдых. При обратном отсчёте она убывает, в рабочей фазе «На время» растёт. Тонкая шкала показывает работу/отдых всех раундов пропорционально их длительности, без подготовки и последнего отдыха. При обратном отсчёте цветной остаток убывает с правого сегмента справа налево. Текущий раунд или лимит виден в заголовке.
4. Кликните цифры или любую из полос, чтобы поставить на паузу; повторный клик продолжит отсчёт. То же действие у круглой кнопки с иконкой паузы/воспроизведения. На паузе справа появляется круглый «Сброс»: он сразу запускает ту же программу с подготовкой без подтверждения. Верхняя стрелка после подтверждения прерывает занятие и возвращает к режимам. После естественного результата «Повторить» запускает программу заново, стрелка открывает меню сразу; при включённом эффекте конфетти появляется примерно на 5 секунд.
5. На компьютере Space ставит на паузу/продолжает вне полей и интерактивных элементов; на кнопках Space/Enter выполняют обычное действие. Escape только на паузе запускает программу заново, F переключает fullscreen. В диалоге Escape сначала закрывает его; выход из fullscreen через Escape не сбрасывает таймер. Во время ввода, с модификаторами и при удержании клавиши горячие команды не исполняются.
6. В уведомлениях настроек виден статус удержания экрана. «Экран остаётся включённым» появляется после подтверждения браузером. Иначе доступно «Не выключать экран»; при отказе отключите автоблокировку вручную. Таймер ограниченно повторяет запрос при возврате/освобождении, при выходе освобождает удержание. Фоновая вкладка и блокировка кнопкой устройства не входят в гарантию.

Начатый таймер не требует интернета. Для повторного открытия без сети дождитесь «Готов к запуску без сети» в настройках. Здесь же «Подготовить офлайн» повторяет проверку/восстановление кэша при интернете. Первый визит без сети не поддерживается.

Перезагрузка страницы сбрасывает тренировку: сохраняются только параметры. При доступном обновлении завершите тренировку, закройте все вкладки приложения и откройте заново. Другую работающую вкладку не нужно закрывать посреди занятия.

QR-пульт ещё не реализован. Трансляция на TV, фоновый будильник при блокировке телефона и автономное LAN-управление в эту версию не входят.
