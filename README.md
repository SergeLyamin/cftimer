# CF Timer

Таймер для тренировок: на смартфоне — самостоятельный таймер, на большом экране — общий таймер с необязательным управлением с телефона через QR.

**Состояние на 26.10.2026:** локальная версия **0.1.4** опубликована на [timer.lyamin.org](https://timer.lyamin.org/): фазовые полосы, компактное управление, пауза кликом по времени/полосам, конфетти и исправленный ввод. [Результаты проверок](docs/ui-0.1.4-2026-10-26.md). Старый код сохранён в [архиве](archive/README.md); приёмка на реальных устройствах открыта, QR-пульт ещё не реализован. Наличие спецификации не означает готовность функции.

Первый запуск — бесплатный пилот в **1–3 залах**, телевизор с подключённым компьютером. Уже запущенный таймер должен продолжать работать при потере интернета. Один экран — один активный пульт, без аккаунтов. Первый пульт подключается свободно, второй запрашивает передачу у первого; после 60 секунд без связи первого передача доступна автоматически. Reload компьютера сбрасывает сессию; reload телефона-пульта — нет. Smart TV / Android TV — бэклог. Эти ограничения подтверждены владельцем проекта.

## Запуск и проверка

Рекомендуется Node 24 LTS.

```bash
npm ci
npm run dev
```

Проверки: `npm run lint`, `npm test`, `npm run build`, `npm run test:e2e` (после `npx playwright install chromium`). Для проверки PWA: `npm run build`, затем `npm run preview -- --port 43870 --strictPort`.

## Размещение

Текущая версия — статический сайт из `dist/`; для неё достаточно HTTPS-хостинга. Сервер Node понадобится после добавления QR-пульта. Старый домен — `timer.lyamin.org`; Сайт размещён на `dev7` под пользователем `timer`: `~/timer.lyamin.org/www` указывает на каталог релиза. Настройку кэширования Nginx нужно уточнить через администратора. [План деплоя, кэширование и откат](docs/deployment.md).

## Разработка по спецификациям

Выбран **OpenSpec 1.14.3**, схема `spec-driven`. Почему он подходит проекту: [ADR-001](docs/decisions/001-sdd.md).

```bash
npm ci --prefix tooling/openspec --ignore-scripts
npm run spec:list
npm run spec:validate
```

Node.js >=20.19 нужен инструменту OpenSpec; для новой реализации рекомендован Node 24 LTS. OpenSpec установлен изолированно, версия и зависимости закреплены в `tooling/openspec/`. Корневой package.json содержит команды приложения и спецификаций.

- `openspec/specs/` — принятые действующие правила; пока только процесс работы над проектом.
- `openspec/changes/bootstrap-timer-pilot/` — локальный таймер реализован, приёмка на реальных устройствах ещё не завершена.
- `openspec/changes/publish-local-timer-ui/` — публикация нового интерфейса на существующем статическом хостинге и проверка обновления PWA.
- `openspec/changes/add-qr-remote-control/` — следующий этап: комнаты, QR и пульт, ещё не выполнен.
- [Руководство разработчика](docs/development.md) — как переходить от требований к коду и проверке.

Локальный запуск: `npm ci`, затем `npm run dev`. Для автономного режима: `npm run build` и `npm run preview -- --port 43870 --strictPort`. [Инструкция](docs/user-guide.md) и [отчёт о проверках](docs/implementation-2026-10-22.md).

[timer.lyamin.org](https://timer.lyamin.org/) переключён на текущий локальный таймер. QR, передача управления, серверная статистика и счётчики аналитики пока не реализованы. Реальная клавиатура iOS/Android, звук и часовой прогон PC+TV остаются условиями допуска к пилоту.
