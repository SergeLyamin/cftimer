# Proposal

## Why

После архивирования неудачного rewrite у CF Timer нет работающего runtime. Для пилота в 1–3 залах сначала нужен локальный таймер, которому не требуется сеть для продолжения начатой тренировки.

## What Changes

- Создать новую SPA на TypeScript/React/Vite с Tailwind и независимым ядром времени.
- Реализовать AMRAP, For Time с лимитом, интервалы; Tabata/EMOM как пресеты.
- Открывать сразу локально доступную главную без ролей/аккаунтов; дать экран зала и самостоятельный мобильный таймер без QR, общую форму настройки, звук, паузу и защищённый сброс по обновлённой трактовке макетов.
- Уточнение 0.1.2 заменяет прежние варианты навигации/сброса/сведений: стрелка в верхней строке слева от названия на настройке/таймере, немедленный сброс на паузе без диалога, общие настройки вместо динамика/i, безопасная маска времени, все номера раундов с переносом, единая палитра фаз и отключаемая мягкая краевая подсветка. Сохранить Oswald и белые стабильные цифры; семантика полосы заменена следующим уточнением; добавить CF favicon SVG/ICO с offline cache. Горячие клавиши не конфликтуют с диалогами, вводом и выходом из fullscreen. Библиотеки, личные пресеты и UX-эксперименты с колесом/выделением пары остаются бэклогом.
- Следующая правка после 0.1.2: полоса текущей фазы высотой 50 px (countdown 1→0, рабочий For Time 0→1), одноколоночные интервалы со свёрнутым «Время подготовки» и «Старт», работа/отдых до 99:99 с явным ограничением переполнения и уведомлением. Добавить отдельную сохраняемую опцию мягкого конфетти при естественном завершении. Сначала локальный desktop и просмотр владельцем; остальные проверки и публикация требуют последующих явных одобрений согласно AGENTS.md.
- Локальная UI-итерация 27.10.2026: шкала раундов 3 px; скрыть видимые двоеточия крупного отсчёта с сохранением ячеек и доступного времени; семантический focus полей. Увеличить pause/resume до 56 px, отнести reset 40 px на 28 px и симметрично показать редактирование на паузе. Упростить главную; показывать «ТЫ МОЛОДЕЦ! 🏆» без полос в результате; конфетти оседает внизу и остаётся до ухода/повтора/выключения. Это новая локальная итерация: одобрение UI и публикации предыдущих релизов на неё не распространяется.
- Обеспечить локальное продолжение при потере сети и cached offline startup через PWA; второй пункт — предлагаемое дополнение к подтверждённому требованию владельца.
- Дать общие настройки на всех экранах: звук с проверкой при включении, эффекты с кратким демо при включении, горячие клавиши; внизу фактическая версия сборки и «GitHub автора» на репозиторий без отдельной подписи авторства. Подготовка публичной политики остаётся BL-02.
- При reload компьютера сбрасывать активный таймер и сессию; сохранять только последние параметры, не active snapshot.
- Закрепить зависимости, команды сборки и meaningful tests.
- Не включать remote, аккаунты, платежи, многоэкранную синхронизацию и Smart TV. Production rollout — отдельный change.

## Capabilities

### New Capabilities
- `timer-operation`: режимы, временные переходы, пауза, валидация, точность при задержке callbacks.
- `gym-display`: читаемый общий и самостоятельный мобильный экран, настройка, звук, браузерные ограничения и управление.
- `offline-continuity`: автономный runtime, cache/reload, безопасные обновления.

### Modified Capabilities
Нет. Runtime baseline отсутствует; project-workflow не изменяется.

## Impact

Создаются новые src, entrypoint, configs, package dependencies и тесты в активном проекте. Архив не изменяется. Сетевого API пока нет. Макеты используются как reference; старые ошибочные promises из документов не переносятся. После завершения этот change становится зависимостью add-qr-remote-control.
