# Proposal

## Why

Владелец принял визуальные правки 23.10.2026, затем уточнил взаимодействие 26.10.2026 и поручил документирование, push и деплой. Проверенный интерфейс нужно опубликовать на существующем timer.lyamin.org с возможностью вернуть предыдущую версию.

## What Changes

- Сохранить отчёт об интерфейсе и результаты проверок, отправить коммиты в origin/main.
- Собрать зафиксированный runtime в dist, упаковать релиз с SHA256, передать под timer на dev7 и переключить www атомарно.
- Сохранить предыдущий релиз и hash-assets для старых вкладок; проверить HTTPS, новый интерфейс, offline и переход с установленного SW.
- Записать фактический commit, каталог, проверки, ограничения кэширования хостинга и откат.
- Повторный выпуск 26.10: опубликовать f325d81 с устойчивым readout, прогрессом, новыми подтверждениями и Wake Lock; сохранить предыдущий 082c009.
- Выпуск 0.1.2 по принятому плану: опубликовать исправленную маску, управление, единые настройки, фазовые эффекты, индикаторы раундов и favicon; сохранить f325d81 для отката. Приёмка интерфейса и требования учтены в разделе 8 bootstrap-timer-pilot.

- Выпуск 0.1.3: последнее сообщение владельца явно одобряет текущий UI и поручает после добавления toggle по цифрам/полосам выполнить необходимые проверки и production deployment. Подготовить проверенный runtime с фазовым прогрессом, сегментированной шкалой, компактными controls, новым вводом и мягким завершением; предыдущий runtime 7bf4b91 (0.1.2) сохранить для отката. Фактический commit/публикация 0.1.3 пока не зафиксированы.

## Capabilities

### New Capabilities

Нет. Операционная публикация уже реализованного интерфейса; `skip_specs: true`.

### Modified Capabilities

Нет. Требования локального таймера остаются в bootstrap-timer-pilot. Публикация не означает завершение аппаратной приёмки.

## Impact

Существующий статический сайт timer.lyamin.org и каталоги /home/timer/timer.lyamin.org/releases, www. Документы и артефакты выпуска; без изменений таймерного ядра, backend, DNS или сервисов других сайтов. Предыдущие публикации выполнены под timer через SSH-аутентификацию, предоставленную владельцем. Новый выпуск 0.1.3 остаётся pending до проверок и фактического переключения. Настроенный ключ отклонён; пароль использован только для установления отдельной временной сессии.
